Start current work with these procedures:

- [Component-first design](./component-first-design.md): exact identities, evidence, schematic and integration checks.
- [JLCPCB package preparation](./jlcpcb-package.md): export one consistent board revision and review the release reports.
- [Renewal prototype bring-up](./renewal-bring-up.md): current pin maps, configuration, staged loads and qualification.
- [KiCad parts download](./kicad-parts-download.md): importing assets for verification against manufacturer drawings.

Earlier converter, regulator, net-table and export guides remain at their original
URLs for traceability. Their historical banners identify instructions that must
be adapted to the renewed hardware. See the [archive](../archive/index.mdx).
