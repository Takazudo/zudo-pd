# Shared P15 r1

> **Development navigation candidate.** The existing P15 owner and physical acceptance gates remain unchanged.

P15 r1 is the 15 V / 3 A input module shared by LED Lamp first and PD15 afterward. Its owner is `boards/board-p15/`; the LED source tree carries a pinned consumer reference. A matching source hash does not show that an individual unit was programmed or tested.
