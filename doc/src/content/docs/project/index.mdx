zudo-pd is a USB-C powered supply for modular synthesizers. The design separates the
USB-PD input module from the board that produces +12 V, −12 V and +5 V.

The renewed documentation starts with current architecture and exact component
records. Previous board orders, debugging notes and superseded design explanations
are available in the [Archive](../archive/index.mdx).

1. Read the [project brief](./project-brief.md) for targets and evidence limits.
2. Use the [repository map](./repository-map.md) to find project sources and checks.
3. Follow the [architecture](../architecture/index.mdx) for board roles and interfaces.
4. Use the [component catalog](/docs/components/catalog/) for actual selected parts,
   pin maps, footprints and source evidence.
5. Follow the [design workflow](./component-first-design.md) when changing a part,
   schematic, PCB or manufacturing package, and use the [procedures](./procedures.mdx)
   for repeatable design and manufacturing work.
