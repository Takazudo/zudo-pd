These pages preserve earlier reasoning and physical-board history. They may describe
superseded parts, the combined-board layout, untested estimates or previous split-board
states. Use the [current architecture](../architecture/index.mdx) and
[component catalog](/docs/components/catalog/) for renewed work.

Old URLs remain because component evidence and bench records cite them. An archived
design statement does not override an exact current component record or schematic spec.

## Current mechanical files

The [printed-accessory index](https://github.com/Takazudo/zudo-pd/blob/main/3dp-files/README.md)
describes the current adhesive leg. The current board uses screw terminals and
a plain left edge, with no printed connector guard. Only the latest renewal CAD,
printed parts and prototype outputs are maintained. This knowledge archive keeps
useful design reasoning, instructions and evidence from actual earlier orders;
it is not a collection of renewal CAD backups or released products.
