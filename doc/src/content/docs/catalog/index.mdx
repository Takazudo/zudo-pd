The LED candidate table preserves original manufacturer, full MPN, package, order code and line DNP flag. The 17 shared line IDs remain separate identities until source, CAD and use evidence is reviewed. The 18 LED-only lines are proposed additions, not active PD records. No LED raw resource, asset or generated component page is imported into PD's public catalog by this development candidate.
