# Superseded 150 × 115 mm prototype

This is the larger pre-compaction Board B layout and its routing inputs. Its
component targets remain relevant, but its dimensions, left connector direction,
interior pogo placement and some 3D transforms were superseded by the compact
layout in `../../board-b.kicad_pcb`. The scripts are historical snapshots and
are not entry points for the active fabrication workflow.

Use the current compact review package and current `scripts/pcb` tools.
