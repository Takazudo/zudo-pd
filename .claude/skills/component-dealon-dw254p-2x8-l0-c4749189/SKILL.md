# DEALON DW254P-2X8-L0 (C4749189)

Run the central validator and read every JSON artifact in this directory. This
renewal connector replaces the old unshrouded header and printed guard system.
Exact distributor identity is confirmed. The retrieved PDF is a genuine DEALON
family drawing with an explicit 16P dimension row, but it is a distributor mirror:
its electrical and mechanical claims remain UNSOURCED at primary-source level.
The direct LCSC `/datasheet/C4749189.pdf` endpoint returned HTML; use the verified
mirror URL in sources.json, never relabel that HTML response a datasheet.

The imported footprint's 1.10mm drill was corrected to the drawing's 1.02mm;
body width/depth are 27.94mm/9mm. Pad1 is square at (+8.89,-1.27) and mating is
+Y. The mirrored drawing has a pin1 triangle but no numeric contact map, so
EasyEDA contact numbering remains an explicit physical verification item.

Current pin groups: 1/2 -12V, 3..8 GND, 9/10 +12V, 11/12 +5V, 13/14 CV,
15/16 GATE. This intentionally changes the historical header's numbers to
match the Doepfer pin1/red-stripe convention. Confirm each rail with a meter
through the actual keyed ribbon cable before first power. A shroud does not
make incorrectly crimped cables safe. Budgets are shared by J10/J11.

JLCPCB lists wave soldering. The mirror drawing states +220C for4s maximum;
confirm the assembly process or hand solder. No SMT/reflow compatibility is
claimed. No 3D-printed guards or guard-shaped PCB edge notches are required.
